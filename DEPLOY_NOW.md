```

### **Step 4: Enter Your Repository**
```
You'll see a text field asking for Git URL
Paste this exactly:

```

- Framework Preset: Vite ✓
- Build Command: npm run build ✓

```
You'll see a progress screen:

✓ Optimizing bundle

## 🆘 If Something Goes Wrong

### Deployment Failed?
```
1. Go to: Vercel Dashboard
2. Click: Your project name
3. Click: "Deployments" tab
4. Find the failed deployment
5. Click: "Logs" button
6. Read the error message
7. Fix the issue locally
8. Push to GitHub
9. Vercel auto-redeploys
```

### CSV Files Not Found?
```
1. In terminal, run: git status
2. If CSV files listed → already good!
3. If NOT listed:
   git add matches.csv deliveries.csv
   git commit -m "Add CSV files"
   git push origin main
4. Vercel auto-redeploys with files
```

### Site Looks Wrong?
```
1. Hard refresh: Ctrl+Shift+R (Windows)
2. Clear cache: Ctrl+Shift+Delete
3. Or wait 5 minutes for cache to clear
4. Check Vercel Deployments for new build
```
