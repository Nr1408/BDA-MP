✅ STEP 1: Sign Up (1 minute)

1. Open: https://vercel.com/signup
2. Click: "Continue with GitHub"
3. Click: "Authorize Vercel"
4. Done! ✓

─────────────────────────────────────────────────────────────────

✅ STEP 2: Import Your Project (1 minute)
─────────────────────────────────────────────────────────────────

1. You're now on Vercel dashboard
2. Click: "Add New" → "Project"
3. Click: "Import Git Repository"
4. Paste: https://github.com/Nr1408/BDA-MP.git
5. Click: "Import"
6. Vercel auto-finds your project ✓

─────────────────────────────────────────────────────────────────

✅ STEP 3: Verify Settings (1 minute)
─────────────────────────────────────────────────────────────────

Vercel shows these (should be auto-detected):

   Framework Preset: Vite ✓
   Build Command: npm run build ✓
   Output Directory: dist ✓
   Install Command: npm install ✓

If they look right, click: "Deploy"

─────────────────────────────────────────────────────────────────

✅ STEP 4: Deploy! (30-90 seconds)
─────────────────────────────────────────────────────────────────

1. Click: "Deploy" button
2. See progress screen
3. Wait for: "Congratulations!"
4. Click: "Visit"
5. Your live dashboard opens! 🎉

❓ CSV FILES NOT LOADING?
─────────────────────────────────────────────────────────────────

Both files MUST be in your GitHub repo:
   • matches.csv ✓
   • deliveries.csv ✓

Check:
   1. git status
   2. Both files listed?
   3. If not:
      git add matches.csv deliveries.csv
      git commit -m "Add CSV files"
      git push origin main

Vercel auto-redeploys with files! ✓

─────────────────────────────────────────────────────────────────

🛠️  BUILD FAILED?
─────────────────────────────────────────────────────────────────

1. Go to Vercel Dashboard
2. Click "Deployments"
3. Click failed deployment
4. Click "Logs"
5. Read error message
6. Fix locally
7. git push → auto-redeploy
