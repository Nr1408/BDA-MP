# 🚀 Quick Start Guide

## Get Started in 2 Steps

### Step 1: Start Development Server
```bash
cd "c:\BDA MP"
npm run dev
```

The dashboard will automatically open at `http://localhost:3000`

### Step 2: Explore the Dashboard
- Click through the tabs to view different analyses
- Interact with charts to see tooltips
- Select teams to view their performance breakdown

## 📊 What You Can See

1. **Overview**: Overview of total matches, teams, and key statistics
2. **Team Stats**: Which teams won the most matches
3. **Player Stats**: Top batsmen and bowlers across all seasons
4. **Venue Analysis**: Match outcomes across different stadiums
5. **Match Analysis**: How toss decisions and match result types compare

## 🛑 Stop the Server
Press `Ctrl+C` in the terminal

## 📦 Build for Production
```bash
npm run build
```

Output will be in `dist/` folder - ready to deploy!
