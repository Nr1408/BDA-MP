1.1 Project Definition

CRICANALYTICS is a comprehensive, full-featured interactive analytics dashboard
designed to process and visualize Indian Premier League (IPL) cricket data. The
project leverages modern web technologies to transform raw cricket datasets into
actionable insights through interactive visualizations, real-time analytics, and
responsive user interface.

The project processes:
- 1,095 IPL matches spanning 17 seasons (2008-2024)
- 260,920+ ball-by-ball delivery records
- Data from 8+ franchises and 20+ cricket venues
- Multiple analytical dimensions: teams, players, venues, toss decisions

1.2 Project Objectives

PRIMARY OBJECTIVES:
✅ Develop an interactive web-based cricket analytics dashboard
✅ Process and analyze large cricket datasets efficiently
✅ Create intuitive visualizations for complex metrics
✅ Provide actionable insights from historical match data
✅ Demonstrate proficiency in modern web development
✅ Build a production-ready application

SECONDARY OBJECTIVES:
✅ Ensure responsive design across all devices
✅ Optimize performance for large datasets
✅ Implement modern UI/UX best practices
✅ Provide comprehensive documentation
✅ Create a professional portfolio project

1.3 Why This Project?

PROBLEM STATEMENT:
Cricket generates massive amounts of data, but traditional analysis is:
- Limited to static tables and basic charts
- Non-interactive and difficult to explore
- Not accessible on mobile/tablet devices
- Requires backend infrastructure
- Difficult to correlate multiple variables

SOLUTION - CRICANALYTICS:
✅ Interactive, real-time analytics platform
✅ Client-side processing (no backend needed)
✅ Responsive design (mobile, tablet, desktop)
✅ Fast performance with minimal dependencies
✅ Professional, intuitive interface

FUNCTION 3: getMatchesByYear(matches)
──────────────────────────────────────────────────────────────────
Purpose: Aggregate matches by IPL season
Parameters: matches (Array of match objects)
Returns: Array<{season: String, matches: Number}>
Algorithm:
  1. Create yearMap object
  2. Iterate through all matches
  3. Count matches per season
  4. Convert to array format
  5. Sort chronologically
Output Example:
  [
    {season: "2008", matches: 59},
    {season: "2009", matches: 57},
    ...
    {season: "2024", matches: 74}
  ]
Used In: MatchesByYear.jsx component
Visualization: Bar chart

FUNCTION 4: getTeamWinStats(matches)
──────────────────────────────────────────────────────────────────
Purpose: Calculate win/loss statistics for each team
Parameters: matches (Array of match objects)
Returns: Array<{team: String, wins: Number, losses: Number, total: Number}>
Algorithm:
  1. Create teamStats object
  2. Iterate through matches
  3. Count wins (match.winner == team)
  4. Count losses (match.winner != team AND team participated)
  5. Sort by wins descending
  6. Return top teams
Calculation:
  - Wins = Count where team is winner
  - Losses = Count where team participated but didn't win
  - Total = Wins + Losses
  - Win Rate = (Wins / Total) * 100
Output Example:
  [
    {team: "Chennai Super Kings", wins: 142, losses: 105, total: 247},
    {team: "Mumbai Indians", wins: 120, losses: 98, total: 218},
    ...
  ]
Used In: TeamStats.jsx component
Sorting: By wins descending (top teams first)

FUNCTION 5: getTopBatsmen(deliveries)
──────────────────────────────────────────────────────────────────
Purpose: Identify top 15 batsmen by total runs
Parameters: deliveries (Array of delivery objects)
Returns: Array<{batter: String, runs: Number, balls: Number, 
                 strikeRate: String, average: String}>
Algorithm:
  1. Create batsmenStats object
  2. Iterate through deliveries
  3. Sum total_runs for each batter
  4. Count balls faced
  5. Calculate Strike Rate: (runs/balls)*100
  6. Calculate Average: runs/balls
  7. Sort by runs descending
  8. Return top 15
Calculations:
  - Strike Rate = (Runs Scored / Balls Faced) × 100
  - Average = Runs Scored / Balls Faced
Output Example:
  [
    {batter: "Virat Kohli", runs: 7500, balls: 5200, 
     strikeRate: "144.23", average: "1.44"},
    ...
  ]
Used In: TopPlayers.jsx (Batsmen tab)
Filtering: Top 15 players only
Sorting: By runs descending

FUNCTION 6: getTopBowlers(deliveries)
──────────────────────────────────────────────────────────────────
Purpose: Identify top 15 bowlers by wickets taken
Parameters: deliveries (Array of delivery objects)
Returns: Array<{bowler: String, wickets: Number, runs: Number, 
                balls: Number, economy: String}>
Algorithm:
  1. Create bowlerStats object
  2. Iterate through deliveries
  3. Count wickets (is_wicket == 1)
  4. Sum runs conceded
  5. Count balls bowled
  6. Calculate Economy: (runs/(balls/6))
  7. Sort by wickets descending
  8. Return top 15
Calculations:
  - Economy Rate = Runs Conceded / Overs Bowled
  - Overs = Balls / 6
  - Example: 40 runs in 5 overs = 8.0 economy
Output Example:
  [
    {bowler: "Lasith Malinga", wickets: 170, runs: 1900, 
     balls: 1200, economy: "9.5"},
    ...
  ]
Used In: TopPlayers.jsx (Bowlers tab)
Filtering: Top 15 players only
Sorting: By wickets descending

FUNCTION 7: getWinByVenue(matches)
──────────────────────────────────────────────────────────────────
Purpose: Analyze match outcomes by venue
Parameters: matches (Array of match objects)
Returns: Array<{venue: String, matches: Number, runsWins: Number, 
                wicketsWins: Number, runsPercentage: String, 
                wicketsPercentage: String}>
Algorithm:
  1. Create venueStats object
  2. Iterate through matches
  3. Count total matches per venue
  4. Count wins by runs
  5. Count wins by wickets
  6. Calculate percentages
  7. Sort by match count descending
  8. Return top 10
Calculations:
  - Runs Win % = (Wins by Runs / Total Matches) × 100
  - Wickets Win % = (Wins by Wickets / Total Matches) × 100
Output Example:
  [
    {venue: "Eden Gardens", matches: 52, runsWins: 24, 
     wicketsWins: 28, runsPercentage: "46.2", 
     wicketsPercentage: "53.8"},
    ...
  ]
Used In: VenueStats.jsx component
Filtering: Top 10 venues
Sorting: By match count descending
Insights: Identifies batting-friendly vs bowling-friendly venues

FUNCTION 8: getRunsPerOver(deliveries)
──────────────────────────────────────────────────────────────────
Purpose: Calculate average runs per over (1-20)
Parameters: deliveries (Array of delivery objects)
Returns: Array<{over: Number, avgRuns: String, totalRuns: Number}>
Algorithm:
  1. Create oversData object
  2. Iterate through deliveries
  3. Group by over number (0-19)
  4. Sum total runs per over
  5. Count deliveries per over
  6. Calculate average: totalRuns / deliveries
  7. Sort by over ascending
Output Example:
  [
    {over: 0, avgRuns: "8.34", totalRuns: 12500},  // PowerPlay start
    {over: 1, avgRuns: "7.89", totalRuns: 11800},
    ...
    {over: 19, avgRuns: "10.54", totalRuns: 15800} // Death overs
  ]
Used In: RunsPerOver.jsx component
Visualization: Area chart showing trend
Analysis: Powerplay (1-6) vs Middle (7-15) vs Death (16-20) overs

FUNCTION 9: getTossDecisionImpact(matches)
──────────────────────────────────────────────────────────────────
Purpose: Analyze impact of toss decision on match outcome
Parameters: matches (Array of match objects)
Returns: Array<{decision: String, wins: Number, total: Number, 
                winPercentage: String}>
Algorithm:
  1. Create tossStats object for bat/field
  2. Iterate through matches
  3. Count total matches per decision
  4. Check if toss_winner == match winner
  5. Count wins for each decision
  6. Calculate win percentage
  7. Return structured array
Calculations:
  - Win % = (Wins / Total Matches) × 100
Output Example:
  [
    {decision: "Bat", wins: 256, total: 502, winPercentage: "51.0"},
    {decision: "Field", wins: 239, total: 497, winPercentage: "48.1"}
  ]
Used In: TossAnalysis.jsx component
Visualization: Bar chart comparison
Insights: Slight advantage to toss winning (~51%)

FUNCTION 10: getMatchResultTypes(matches)
──────────────────────────────────────────────────────────────────
Purpose: Categorize matches by result type
Parameters: matches (Array of match objects)
Returns: Array<{type: String, count: Number, percentage: String}>
Algorithm:
  1. Create resultTypes object
  2. Iterate through matches
  3. Group by result field
  4. Count each result type
  5. Calculate percentages
  6. Return structured array
Result Types in IPL:
  - "runs" = Match won by runs
  - "wickets" = Match won by wickets
  - "tie" = Tied match
  - "no result" = No result
Output Example:
  [
    {type: "runs", count: 498, percentage: "45.5"},
    {type: "wickets", count: 578, percentage: "52.8"},
    {type: "tie", count: 14, percentage: "1.3"},
    {type: "no result", count: 5, percentage: "0.5"}
  ]
Used In: TossAnalysis.jsx (Result Types section)
Visualization: Pie chart with legend
Insights: Slightly more matches won by wickets (52.8%)
